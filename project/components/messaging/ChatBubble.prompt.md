One WhatsApp message bubble for mocking the order flow.

```jsx
<ChatBubble from="customer" time="09.40">Mas, 1L gula aren masih ada?</ChatBubble>
<ChatBubble from="shop" time="09.41">{"Ada! Ready 4 botol.\nMau dikirim atau ambil sendiri?"}</ChatBubble>
```

Deliberately NOT brand-coloured: WhatsApp controls type and colour, so KUPI's design lives in line breaks, order of information and rhythm. Compose inside `PhoneScreen`.
