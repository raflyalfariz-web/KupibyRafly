One Lucide glyph, sized and coloured — use it anywhere KUPI needs an icon, never a hand-drawn SVG or emoji.

```jsx
<Icon name="message-circle" size={24} color="var(--text-on-ink)" />
```

Requires `<script src="https://unpkg.com/lucide@0.453.0/dist/umd/lucide.min.js"></script>` on the page. Lucide is a flagged substitution: KUPI has no icon library of its own. Do not use it for the WhatsApp mark — that glyph must come from WhatsApp's own brand assets.
