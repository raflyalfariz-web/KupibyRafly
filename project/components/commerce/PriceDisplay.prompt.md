Size + rupiah price, Zilla Slab 600 tabular. Prices are always full rupiah with id-ID separators — never "20k".

```jsx
<PriceDisplay size="500ml" price={22000} note="cukup 2 gelas" />
<PriceDisplay size="1L" price={40000} emphasis="hero" layout="stack" />
```

`row` for menu lists, `stack` for cards. `was` shows a struck original — promos only.
